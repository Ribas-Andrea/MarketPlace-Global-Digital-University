## Présentation

Application backend de gestion de commandes pour un restaurant, développée avec **Node.js, Express et MongoDB**.
Elle propose une API permettant de gérer les produits, menus, utilisateurs et commandes.

🔗 Accès à l'API : https://marketplace-seven-steel.vercel.app/api-docs/#/
🚀 Vercel : https://marketplace-seven-steel.vercel.app
📚 Swagger : http://localhost:3000/api-docs
